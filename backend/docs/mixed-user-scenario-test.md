# 개선 전 API 혼합 사용자 시나리오 성능 테스트

## 목적

단일 API의 최대 RPS가 아니라, 서로 다른 앱 사용 흐름 40개가 섞인 상태에서 개선 전 API 서버가 감당할 수 있는 최대 동시 사용자(VU)를 측정한다.

대상 이미지는 `modera-api:132`이며 현재 버전 `modera-api:133`은 비교 측정하지 않는다.

## 판정 기준

- 전체 비즈니스 API p95 응답시간: 300ms 이하
- 비즈니스 API 실패율: 1% 미만
- 비즈니스 check 성공률: 99% 이상
- 전체 사용자 흐름 성공률: 99% 이상
- 테스트 중 1초 간격 헬스체크 성공률: 100%
- 테스트 종료 후 API 정상 응답 및 컨테이너 생존

동시 사용자 수는 k6 `constant-vus`의 VU 수다. 각 VU는 자신에게 배정된 흐름을 반복하며 API 호출 사이에 기본 0.3초의 실제 사용자 행동 간격을 둔다. 40개 흐름은 VU와 반복 횟수를 기준으로 순환 배정된다.

## 복합 사용자 세션 v2

초기 측정의 일부 흐름이 단일 목록 조회로 끝나 실제 앱 세션보다 약하다는 판단에 따라 다음과 같이 강화한다.

- 각 VU가 고유 `deviceId`로 직접 로그인한 뒤 세션 시작
- 모든 세션 공통 진입 과정: 내 정보 → 카테고리 → 카테고리 이미지 목록
- 시나리오별 핵심 행동 1~6단계 실행
- 세션별 후속 행동 2~3단계: 상세·연관 이미지·페이지 이동·일정·문서·즐겨찾기
- 한 세션이 최소 6개, 최대 12개 비즈니스 API 호출
- API 사이 행동 간격을 고정값이 아닌 0.3~1.2초 범위로 변동
- VU와 반복 횟수에 따라 40개 전체 흐름과 후속 분기를 순환

따라서 v2에서 VU는 단순 반복 요청자가 아니라 로그인 후 여러 화면을 이동하는 동시 앱 사용자 한 명을 의미한다.

## 제외 범위

- 실제 LLM 토큰을 소비하는 문서 생성·재생성·카테고리 재분석
- 대량 이미지 업로드와 삭제
- 사용자 전체 데이터 초기화
- 외부 FCM 실제 발송

위 작업은 비용 또는 복구 불가능한 데이터 변경을 만들 수 있으므로 이번 동시 사용자 용량 테스트에서 제외한다. 이미지 분석 파이프라인 용량은 별도 파이프라인 테스트 결과를 사용한다.

## 실행 방식

```bash
docker run --rm --network infra_default \
  -e BASE_URL=http://modera-api-old:8080 \
  -e VUS=40 \
  -e DURATION=2m \
  -e THINK_TIME=0.6 \
  -v /home/ubuntu/k6:/scripts:ro \
  grafana/k6 run /scripts/mixed-user-scenarios.js
```

동시 사용자 수를 단계적으로 높이고 마지막 통과 단계와 최초 실패 단계를 모두 기록한다.

### 판정

- `p95 <= 300ms`를 만족하는 최대 확인 동시 사용자: **350 VU**
- 최초 실패 동시 사용자: **375 VU**
- 포화 경계: **350~375명 사이**
- 안전 운영 권장 범위: **300 VU 이하**
- 혼합 트래픽 최대 처리량: 약 **789 req/s**

350 VU의 API p95는 285.74ms로 기준까지 약 14ms밖에 남지 않았다. 375 VU부터 오류나 서버 장애가 발생한 것은 아니지만 p95가 332.79ms로 증가해 응답시간 기준을 위반했다. 300 VU 이후 처리량은 약 788 req/s 부근에서 더 증가하지 않고 응답시간만 상승했다. 따라서 이전 버전의 주된 포화 신호는 요청 실패보다 서버 내부 대기 증가다.

## 해석 시 주의사항

- 40개 흐름의 호출 수가 서로 다르기 때문에 VU 수와 RPS는 일대일 대응하지 않는다.
- 테스트 계정 하나의 기존 데이터를 여러 VU가 공유한다. 실제 사용자별 데이터 분산에 따른 DB 캐시 적중률 차이는 반영하지 않는다.
- 문서 생성·이미지 업로드·AI 재분석 파이프라인은 비용과 데이터 오염 방지를 위해 제외했다.
- 결과의 `350명`은 본 문서의 40개 혼합 흐름과 0.3초 행동 간격에서 성립하는 최대 확인값이다.
